Renditions

The renditions system is the client-side equivalent of ASC v1's AssetRenditionDispatcher. It resolves download URLs for each asset based on definitions in configurations.js — no server-side code required.

Overview

Three rendition types map to the three AEM delivery patterns:

TypeAEM v1 equivalentWhen to use
static StaticRenditionDispatcher JCR rendition nodes in jcr:content/renditions/*. Works on any AEM.
url ExternalRedirectRenderer Legacy Dynamic Media / Scene7 IS/IR protocol (is/image/ URLs). AEM 6.5 or classic DM.
asset-delivery AssetDeliveryRenditionDispatcher DM with OpenAPI — plain transforms, smart crops, named presets. AEMaaCS only.
Two different Dynamic Media systems Legacy DM (Scene7 / IS-IR) uses type: 'url' with ${dm.*} metadata variables. DM with OpenAPI (Next Gen DM, AEMaaCS) uses type: 'asset-delivery' with query params — smart crops and named presets are just different params values on the same URL.

type: 'static'

Matches a named node from the asset's jcr:content/renditions/* tree. The URL is constructed from the known JCR path — no external API needed. 

{
  id: 'web',
  label: 'Web',
  type: 'static',
  name: /^cq5dam\.web\./,   // RegExp — matches cq5dam.web.1280.1280.jpeg etc.
  accepts: 'image/*',       // only applies to image assets
},
{
  id: 'original',
  label: 'Original',
  type: 'static',
  name: 'original',         // exact string match
},

The name property is either an exact string or a RegExp tested against the rendition node name. The resolved URL is: {aem.host}{asset.path}/_jcr_content/renditions/{nodeName}

type: 'url' — Legacy Dynamic Media

Constructs a URL by interpolating ${variable} placeholders. Use for AEM 6.5 or AEMaaCS instances with classic Scene7 Dynamic Media enabled. Variable values are read from dam:scene7* metadata properties written to the asset by the DM sync process. 

// Named preset
{
  id: 'dm-web',
  label: 'Web',
  type: 'url',
  url: '${dm.apiServer}is/image/${dm.file}?$web$',
  accepts: (asset) => !!asset.getProperty('dam:scene7File'),
},

// Smart Crop (IS/IR ":CropName" syntax)
{
  id: 'dm-smart-crop-small',
  label: 'Smart Crop — Small',
  type: 'url',
  url: '${dm.apiServer}is/image/${dm.file}:Small',
  accepts: (asset) => !!asset.getProperty('dam:scene7File'),
},

// Image preset
{
  id: 'dm-grayscale',
  label: 'Grayscale',
  type: 'url',
  url: '${dm.apiServer}is/image/${dm.file}?$grayscale$',
},

type: 'asset-delivery' — DM with OpenAPI

Constructs an AEM Asset Delivery URL using the asset's UUID. AEM as a Cloud Service only. Requires aem.deliveryHost in configurations.js.

Generated URL format:

{deliveryHost}/adobe/dynamicmedia/deliver/{uuid}/{filename}.{ext}?{params}

Smart crops, named presets, and plain image transforms all use this same URL base — they're just different params values: 

// Requires: aem.deliveryHost set in configurations.js

// Plain image transform (no DM license needed)
{
  id: 'web-optimized',
  label: 'Web Optimized',
  type: 'asset-delivery',
  params: 'format=webp&preferwebp=true&width=1200&quality=85',
  accepts: 'image/*',
},

// DM OpenAPI Smart Crop
{
  id: 'smart-crop-small',
  label: 'Smart Crop — Small',
  type: 'asset-delivery',
  params: 'smartcrop=Small',   // crop name must match your DM preset
  accepts: 'image/*',
},

// DM OpenAPI Named Image Preset
{
  id: 'dm-preset-web',
  label: 'Web Preset',
  type: 'asset-delivery',
  params: 'imagePreset=web',
  accepts: 'image/*',
},
Enable deliveryHost Add deliveryHost: 'https://delivery-pXXXX-eYYYY.adobeaemcloud.com' to the aem section in configurations.js. Without it, type: 'asset-delivery' renditions silently resolve to null.

The accepts filter

Controls which asset types a rendition definition applies to:

// Apply to all assets (default — omit accepts)
{ id: 'original', type: 'static', name: 'original' }

// MIME type glob string
{ ..., accepts: 'image/*' }      // images only
{ ..., accepts: 'video/*' }      // videos only
{ ..., accepts: 'application/pdf' }  // PDFs only

// Function — full asset access
{
  ...,
  accepts: (asset) => !!asset.getProperty('dam:scene7File'),
}

The visible flag

Set visible: false to hide a rendition from the download list while keeping it available internally via services.renditions.getRendition(asset, id). Used for the thumbnail rendition, which powers teaser images. 

{
  id: 'thumbnail',
  label: 'Thumbnail',
  type: 'static',
  name: /^cq5dam\.thumbnail\./,
  visible: false,  // shown to teasers, hidden from download list
}

Template variables (type: 'url')

VariableResolves toJCR metadata property
${asset.path}JCR path—
${asset.name}Node name (filename)—
${asset.id}UUID—
${asset.extension}File extension—
${asset.title}Display titledc:title
${dm.name}Scene7 asset namedam:scene7Name
${dm.id}Scene7 asset IDdam:scene7ID
${dm.file}Scene7 file path (e.g. company/image)dam:scene7File
${dm.folder}Scene7 folderdam:scene7Folder
${dm.domain}Scene7 domaindam:scene7Domain
${dm.apiServer}Scene7 API server URLdam:scene7APIServer

Default definitions

If renditions.definitions is not set in configurations.js, ASC uses these defaults — suitable for any AEM instance with standard DAM processing profiles: 

// Default definitions (built into scripts/asc/services/renditions/renditions.js)
[
  {
    id: 'thumbnail',
    label: 'Thumbnail',
    type: 'static',
    name: /^cq5dam\.thumbnail\./,
    visible: false,
  },
  {
    id: 'web',
    label: 'Web',
    type: 'static',
    name: /^cq5dam\.web\./,
    accepts: 'image/*',
  },
  {
    id: 'original',
    label: 'Original',
    type: 'static',
    name: 'original',
  },
]

Full configuration example

// scripts/configurations.js
export default {
  aem: {
    host: 'https://publish-pXXXX-eYYYY.adobeaemcloud.com',
    deliveryHost: 'https://delivery-pXXXX-eYYYY.adobeaemcloud.com',
  },

  renditions: {
    definitions: [
      // ── Static (any AEM) ────────────────────────────────────────────────
      { id: 'thumbnail', label: 'Thumbnail', type: 'static',
        name: /^cq5dam\.thumbnail\./, visible: false },
      { id: 'web',       label: 'Web',       type: 'static',
        name: /^cq5dam\.web\./,       accepts: 'image/*' },
      { id: 'original',  label: 'Original',  type: 'static',
        name: 'original' },

      // ── Legacy DM / Scene7 (AEM 6.5 or classic DM) ──────────────────────
      { id: 'dm-web',   label: 'Web (DM)',   type: 'url',
        url: '${dm.apiServer}is/image/${dm.file}?$web$',
        accepts: (asset) => !!asset.getProperty('dam:scene7File') },
      { id: 'dm-crop',  label: 'Smart Crop — Small', type: 'url',
        url: '${dm.apiServer}is/image/${dm.file}:Small',
        accepts: (asset) => !!asset.getProperty('dam:scene7File') },

      // ── DM with OpenAPI / Asset Delivery (AEMaaCS only) ─────────────────
      { id: 'web-opt',  label: 'Web Optimized', type: 'asset-delivery',
        params: 'format=webp&preferwebp=true&width=1200&quality=85',
        accepts: 'image/*' },
      { id: 'sc-small', label: 'Smart Crop — Small', type: 'asset-delivery',
        params: 'smartcrop=Small', accepts: 'image/*' },
      { id: 'preset-web', label: 'Web Preset', type: 'asset-delivery',
        params: 'imagePreset=web', accepts: 'image/*' },
    ],
  },
};
