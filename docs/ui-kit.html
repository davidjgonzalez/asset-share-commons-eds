Buttons

.btn + variant + size. Defined in styles.css.

Variants

Use btn--primary for the single main action; btn--secondary / btn--ghost for the rest; btn--danger for destructive.

Sizes
Circle / icon buttons

Sizes: btn--lg (44px) · default (36px) · btn--sm (28px). Pair btn--circle / btn--icon with a size. Use an SVG (or icon) child — it centers exactly.
