Themeable

Five built-in themes (default, dark, warm, studio, vault) built on a CSS variable design system. Create your own theme in a single CSS file.

default dark warm studio vault
⚡
EDS Native

No build step. Vanilla JS ES modules. Content authored in da.live. Deployed to the AEM CDN. LCP-optimized with eager loading for critical content.

no build da.live AEM CDN
🔌
Extensible

Swap search providers, define custom renditions, add metadata properties, and create new themes — all from a single configurations.js file.

querybuilder dm-openapi scene7

Minimal setup. Works out of the box. 

// scripts/configurations.js — the only file you need to edit

export default {
  aem: {
    host: 'https://publish-pXXXX-eYYYY.adobeaemcloud.com',
  },
  search: {
    provider: 'querybuilder',   // or 'openapi'
  },
  assetDetails: {
    templates: {
      'image/*': '/details/image',
      default:   '/details/default',
    },
  },
  theme: {
    default: 'vault',           // default | dark | warm | studio | vault
  },
};
