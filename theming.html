Theming

A theme is a CSS file that overrides CSS custom properties. No JavaScript involved. All visual customization — colors, spacing, typography, radius, shadows — flows through variables defined in styles/tokens.css.

Activating a Theme

Set theme.default in scripts/configurations.js:

// scripts/configurations.js
theme: {
  default: 'vault',  // 'default' | 'dark' | 'warm' | 'studio' | 'vault'
}

On page load, scripts/scripts.js reads this value, adds theme-{name} to <body>, and loads styles/themes/{name}.css. The theme CSS overrides variables under the .theme-{name} selector.

Creating a Custom Theme

Copy styles/themes/custom.css as your starting point:

/* styles/themes/my-theme.css */
.theme-my-theme {

  /* ── Base ─── */
  --background-color: #f5f5f0;
  --light-color: #ebe9e2;
  --dark-color: #6b6560;
  --text-color: #1a1a1a;
  --link-color: #c44b0a;
  --link-hover-color: #a33c07;
  --border-color: #dddad4;

  /* ── Asset teaser card ─── */
  --asset-teaser-bg: #ffffff;
  --asset-teaser-border: 1px solid #dddad4;
  --asset-teaser-border-radius: var(--border-radius-md);

  /* ── Search ─── */
  --search-primary-color: #c44b0a;
  --search-input-focus-border: #c44b0a;

  /* ── Buttons ─── */
  --button-primary-bg: #c44b0a;
  --button-primary-color: #ffffff;
  --button-primary-hover-bg: #a33c07;
}

Then activate it:

// scripts/configurations.js
theme: { default: 'my-theme' }

Per-Block Theme Overrides

Themes can also override block-level styles directly, not just variables:

/* styles/themes/my-theme.css */

/* Lift cards on hover */
.theme-my-theme .asc-asset-teaser:hover {
  transform: translateY(-3px);
  box-shadow: var(--shadow-lg);
}

/* Pill-shaped search bar */
.theme-my-theme .block.search-bar input {
  border-radius: var(--border-radius-full);
}

/* Ghost-style primary button */
.theme-my-theme .block.details-actions [data-action="download"] {
  background: transparent;
  border: 1px solid var(--link-color);
  color: var(--link-color);
}

See styles/themes/studio.css and styles/themes/vault.css for examples.
