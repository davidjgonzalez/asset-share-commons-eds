Event Integration

The search bar emits the following events:

  • asc:search - When search input changes or button is clicked

The search service emits:

  • asc:search:start - When search execution begins
  • asc:search:complete - When search execution completes successfully
  • asc:search:error - When search execution fails

And listens for:

  • asc:search:clear - To clear the search input

Example usage in JavaScript:

// Listen for search completion events document.addEventListener('asc:search:complete', (event) => { const { results, query, formData } = event.detail; console.log('Search completed:', { results, query, formData }); // Display search results here displaySearchResults(results); }); // Listen for search errors document.addEventListener('asc:search:error', (event) => { const { error } = event.detail; console.error('Search failed:', error); }); // Clear search programmatically document.dispatchEvent(new CustomEvent('asc:search:clear'));
